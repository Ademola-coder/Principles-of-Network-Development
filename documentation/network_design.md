## Comparison of JSON, XML and YAML 

Record: 

JSON 

Advantage: Easy for APIs and programming languages to process. 

Limitation: Large configurations can become difficult to read. 

XML 

Advantage: Provides strict structure using tags. 

Limitation: Requires more text and can become complex. 

YAML 

Advantage: Human-readable and commonly used in automation tools. 

Limitation: Incorrect indentation can cause errors.
